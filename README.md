# SMusic 🎵

A clean, modern, and powerful music streaming application built with Jetpack Compose and Media3.

## ✨ Features

- **Unified Recommendation System**: Spotify/YouTube/Saavn style recommendations based on language and artist affinity.
- **High Fidelity Audio**: Support for high-quality streams with gapless playback and crossfade.
- **Dynamic UI**: Beautiful, glassmorphic player interface with real-time background blurring.
- **Synchronized Lyrics**: Sing along with perfectly timed lyrics.
- **Smart Queue**: Automatic queue refilling to keep the music playing.

## 🛠 Tech Stack

- **Media**: Androidx Media3 (ExoPlayer)

- **Networking**: Ktor
- **Database**: Room
- **State Management**: Kotlin Flow & StateFlow
